# Study MBBS Abroad Project

This project is a responsive website designed to help students explore opportunities to study MBBS abroad. It provides information about top countries, testimonials, FAQs, and a lead form for inquiries.

## Features
- **Responsive Design**: Built using Tailwind CSS for a seamless experience across devices.
- **Interactive Navigation**: Includes a mobile-friendly menu with a toggle button.
- **Sections**:
  - **Why Study Abroad**: Highlights the benefits of studying MBBS abroad.
  - **Top Countries**: Showcases popular destinations with images and descriptions.
  - **Testimonials**: Features feedback from students who have studied abroad.
  - **FAQs**: Answers common questions about studying MBBS abroad.
  - **Lead Form**: Collects user information for inquiries.
- **Font Awesome Icons**: Enhances visual appeal with icons.
